# HealthManager v0.3.0

发布日期：2026-07-15

构建号：8

## 本版重点

- 建立可信饮食记录基础：追加 v5 `meal_items` 快照模型、原子 MealStore、可测试编辑草稿，以及一致的保存/删除/HealthKit 副作用编排。
- 支持低摩擦餐次复用：最近餐、整餐复制、选中菜品复制和常用克数都回到同一编辑与保存路径；历史零分项餐次仍可继续使用。
- 修复历史餐次辨识：复用列表优先显示结构化菜品；没有分项时显示原餐次备注；两者都缺失时明确显示“未记录饮食内容”。该修复不迁移、不重写数据，也不把历史备注复制到新餐草稿。
- 增加分项证据展示：手工、AI、数据库与标签来源、置信度、引用、版本、备餐状态和用户修订事实均按已有证据显示，不推断不存在的事实。
- 交付“今日 / 饮食 / 用药 / 趋势 / 更多”五栏导航与按时间展开的健康证据线；原有来源、同步、设置、报告和诊断能力仍可达。
- 统一饮食摄入、能量缺口、日报/周报和 LLM 输入的 unknown/complete 语义，避免把未知营养静默当成 0。
- 修复睡眠效率证据边界、跨进程遗留同步任务恢复，以及餐次清空营养后的旧 HealthKit 样本删除。
- 完成真机照片生命周期、VoiceOver、最大 Dynamic Type、跨午夜 sleepAnalysis 和后台 observer 验收。

## 兼容与数据安全

- 保持 Bundle ID `com.norte.HealthManager` 与 Team `K8RVJSC4NU`，以同一应用身份覆盖升级。
- 数据库只追加 v5 迁移，不修改 v1～v4，不重写旧餐次。
- v0.3.0 Release 覆盖安装后的真实 iPhone 数据审计：`integrity_check=ok`，迁移为 v1～v5，餐次 115、历史备注餐次 43、测试餐次 0、孤儿分项 0、活动同步任务 0。
- 本版 GitHub Release 提供私有仓库源码与 tag；签名后的 Release App 已直接覆盖安装到验收设备，不是公开 App Store 分发包。
