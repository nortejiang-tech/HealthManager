# HealthManager v0.11.0

2026-10-24 · build 28 · iOS 17+

本版整合佳明持续健康监测、Garmin 优先的双源数据融合、可切换卡片界面、健康速报与 AI 解读弹窗，并统一体重历史统计口径。

## 佳明与双源数据

- 在「更多 → 设置 → 佳明健康监测」导入中国区 Garmin Personal API 密钥并同步。密钥保存在本机 Keychain，不进入备份、Mac 同步或发布包。
- 支持睡眠评分、夜间 HRV、Body Battery 和压力。保留测量日期、更新时间、来源及缺测／错误状态；历史值不冒充实时测量，夜间 HRV 不与 Apple Health SDNN 混用。
- 对 Apple 健康中实际存在的双端运动记录，匹配同场事件，佳明有效数据优先，Apple Watch 做交叉校验、缺段及缺字段补全，同场运动不重复累计。源间冲突和证据不足仍明确显示。
- Garmin Connect 中尚未通过当前公开 Personal API 提供的官方训练准备程度，显示接口未开放，并提供跳转已安装 Garmin Connect App 的入口。设备功能不等于 API 可读能力；不伪造官方分数。
- Mac Bridge 接收规范化佳明指标与运动事件；手机为写入端，Mac 为只读副本。SQLite/WAL 留在各自本地，iCloud 传输批次、清单与回执。

## 健康速报与界面

- 趋势页顶部改为「健康速报」：睡眠环、夜间 HRV、Body Battery 分段图和近期训练负荷，问候语缩小，数据质量与提醒入口保留。
- 手动点击「AI解读」，成功后自动弹窗显示小结、今日安排、引用依据、来源和日期。关闭后可点「查看AI解读」直接重看，弹窗内可重新解读。
- 模型解读必须通过本地事实与状态校验。基线不足时显示基线建立中，缺测不视为休息或健康；结果仅作生活参考，保留与官方训练准备程度的区别。
- AI 复用设置中的文本通道。自动速报解读为独立开关且默认关闭，仅发送结构化聚合事实；手动临时网络／服务端错误最多重试一次，总预算有上限，其他错误分类提示。
- 活力卡片与经典模式可切换；默认以图形和必要文字呈现，详细说明折叠。覆盖深色和辅助大字体，保留原有记录与计算。
- 修复真实数据规模下训练页长期显示计算中、部分展开布局循环及餐次卡片留白无法点击的问题。

## 体重统一口径

- 排除 Garmin 手填体重，仅采纳已确认的可信秤来源；原始记录保留，可查看排除原因。
- 同来源半小时内的读数合并为称重事件，取中位数。按本地四个六小时时段分别取事件中位数，再对有记录时段等权平均，降低连续多次称重带来的频次偏差。缺测不补零，不声称这是连续监测得到的真实全天均值。
- 历史投影、日报、周报和 Mac 采用相同的 `weight-time-strata-v1` 口径，保留来源与时段覆盖。旧报告原文归档，旧 AI 评注失效后重新生成。
- 新增 v16–v18 数据迁移，备份格式升级至 v6。升级前保留备份；旧 App 不应直接导入更高版本备份，不把换回旧二进制视为完整数据库回滚。

## 验证与分发边界

- 最终源码全量 App 单元测试 538 项、Mac Bridge 测试 27 项通过。
- 健康速报最新界面回归 6 项、相关单元测试 19 项通过，覆盖生成成功弹窗、关闭重看、重新解读、失败不弹窗及辅助大字体。
- 维护者已在 iPhone 覆盖安装本版并确认实际验收通过。真实模型请求、历史口径重算、报告归档和手机到 Mac 的一致性已核验；真实健康记录与设备信息保留在本地，不随源码发布。
- 物理 XCTest 驱动连接受限的历史记录与维护者手动验收分开记录；不把模拟器合成数据当作实际设备采集结果。双设备长期佩戴覆盖与工程阈值仍需持续观察，不作医疗准确性承诺。
