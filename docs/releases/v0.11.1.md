# HealthManager v0.11.1

2026-10-25 · build 29 · iOS 17+

本版允许对同一次运动的多源记录手动指定主记录，并让训练统计、历史汇总、日报周报和 Mac 导出遵循同一决定。

## 手动选择计入记录

- 入口：「锻炼 → 最近运动／全部运动 → 运动详情 → 计入记录」。比较候选来源的时间、时长、距离和消耗，选择后保存。
- 默认「自动选择」继续采用佳明优先、其他来源校验补全。手动选择只作用于这次运动，随时可恢复自动。
- 手动选中的有效时间窗口、时长、距离、消耗和重叠时段心率优先；缺失字段与心率空档继续由其他来源补全，并记录来源。真实零值保留，不平均竞争读数。
- 保留原始多端证据，同场运动只统计一次。决定持久保存，重启、重新同步及迟到记录不会无故改回默认来源。所选记录不可用时明确提示并自动补位，原决定保留。
- 训练详情、运动列表、训练负荷和历史使用相同选择；全天步数及非运动的连续健康监测仍遵循各自指标规则。

## 汇总、恢复与 Mac 一致性

- 对无歧义的手选运动，活动能量替换连续数量源中对应运动窗口的消耗，保留非运动时段能量；无法区分的重叠保留连续观测并标明未应用替换，避免重复扣加。
- 修改选择会排队重算相关日期，已有日报周报保留原文归档并失效旧 AI 评注，再按新决定生成确定性摘要。保存不等待无关历史重算队列。
- 聚合写入前核对选择版本，避免旧计算覆盖新决定。恢复旧备份时重新校准已有原始证据的投影，防止已被替换的运动再次成为重复统计。
- Mac 运动投影增加选择模式、所选记录 ID、选择状态与更新时间。早期日期的手选运动也可使用规范化事件，查询时排除重复的旧原始记录。

## 数据升级

新增加法迁移 `v19_workout_record_choices`，备份格式升级至 **v7**，保存手动选择及恢复自动的决定，继续支持读取旧备份。原始样本与密钥不进入备份。升级前保留备份；旧版本不能直接读取更高版本备份，换回旧二进制不等于完整数据库回滚。

## 验证与发布边界

- 已验收源码指纹复核一致；548 项 App 单元测试、27 项 Bridge 测试通过。
- 2 项模拟器界面用例通过，覆盖选择、取消、保存、重启保留、恢复自动及辅助大字体；最终保存流程另有复验。
- 维护者已在实际 iPhone 验收通过；已核对手机到 Mac 的选择模式、日期、所选原始字段和单次计数一致。具体健康记录、设备标识与私有回执不随版本发布。
- 物理 XCTest 驱动受限的历史记录与维护者手动验收分开保存；不将模拟器数据作为实际采集证据。Release 归档和签名检查见随版验证摘要。
- 本次为公开 GitHub 源码版本发布，不是 App Store／TestFlight 分发。个人签名包、密钥、个人健康数据、真机截图与私有验收材料仅保留本机。
