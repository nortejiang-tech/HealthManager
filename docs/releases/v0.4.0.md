# HealthManager v0.4.0

发布日期：2026-07-16

构建号：9

## 本版重点

- 完成全页面 UI 改版：以“基线叙事 + 局部决策透镜”统一今日、饮食、用药、趋势、更多及其编辑、证据、运维和设置下钻。
- 建立轻量设计系统：使用克制的暖色背景、语义色、来源轨道、决策透镜、加载 / 空白 / 恢复组件，同时保留系统导航和原生控件。
- 把未知、合法零值、首次加载、成功空白、后台刷新、失败和部分成功分别表达，不用视觉包装制造不存在的健康事实。
- 补齐深色模式、Dynamic Type、Reduce Motion、VoiceOver 描述和图表可读摘要；颜色不作为唯一状态信号。
- AI 设置明确区分文本评注与照片分析两个通道，并分别提供连接测试；照片连接测试不读取用户照片或健康数据。
- 根据最终人工验收调整趋势与饮食：趋势页优先展示今日数据和指标卡片，把“来源 / 整理 / 展示”移至页面底部；饮食页移除重复的大型新增 / 复用按钮，只保留右上角快捷入口。
