## 本轮交付

### 信息架构：趋势即首页
- 五栏顺序：**趋势 / 饮食 / 用药 / 营养表 / 更多**；冷启动默认趋势页，后台恢复不丢当前页与草稿。
- 「今日」一级页移除：记录动作各归饮食/用药页；质量、来源、日报/周报仍从「更多」进入；Core 汇总逻辑按需保留。

### 营养表（离线官方目录）
- 内置 41 条人工核对的 MEXT《日本食品标准成分表（八订）增补2023》条目（含 2026-03-27 勘误、源文件 SHA-256 存档），覆盖高频食材：蛋、米饭、豆乳、玉米、虾、主要蔬菜、豆腐、肉类、油盐酱、黑咖啡、葵花籽等。
- 页面：搜索（中文名/别名/原文名）+ 分类筛选 + 「参考食材 / 我的常吃」两段；每行每 100 g 可食部分四指标；详情含份量换算（0/负/非有限拒绝）、官方废弃率说明、推定/微量/未测定分别表达、「查看来源」链接与机构署名。
- 官方能量不做 4/4/9 重算；查不到的食物不显示猜测值。

### 我的常吃与个人配方
- 常吃统计：按本地自然日窗口（近 30 天 / 全部历史）、每餐去重、实时重建。
- 三类条目：已匹配官方单品（可置顶、默认份量）、我的配方/固定餐（不可变版本，每份为主、详情每 100 g）、待确认候选（匹配官方 / 补充配方 / 忽略，不重现）。
- 配方计算：同状态食材贡献求和 ÷ 实际成品重；缺任一原料营养素 → 该项未知；未知用量不按 0；缺成品重允许存草稿但不给每 100 g。
- 「加入饮食」全部只生成编辑器草稿，保存走既有 MealStore + HealthKit 协调链；配方分项落库为新来源 `recipe_calculation`（快照，不随配方修订改变）。

### 数据安全
- 数据库 v9 迁移（既有 v1~v8 不动）：`recipe_calculation` 枚举 + 四张个人数据表。
- 备份包 formatVersion 2：新增个人配方/映射三文件；重装恢复幂等；**v0.5.x 旧 App 遇 v2 备份会明确拒绝（提示升级），属预期**；v0.6 可导入 v1 旧备份。

### 体验精简
- 饮食页：历史餐次分页（50/页，不漏不重）+ 菜名/备注搜索 + 日期筛选；合并重复说明。
- 趋势首页：删除与卡片重复的四个今日大数、重复日期与来源流程说明；铃铛角标改为「N 类待检查」。
- 告警页：「当前待检查（N 类）」按指标归组 + 确认此类；历史详情保留。
