## 本轮交付

### 1. 参考食材可整理（D1~D3）
- 参考表改为个人成员列表：右上「＋」添加、左滑移除（带「已移除 · 撤销」横幅，可逆不弹窗）、详情菜单同操作；全部移除后空态提供「添加食材」。
- 移除仅改变成员状态：官方资料保留、旧饮食与旧配方数值不变；重启/升级/备份恢复后不复活已移除条目；重新添加恢复成员、无副本。
- 配方选择器可检索完整官方资料范围（含已移除成员），且不会因此把条目塞回参考表。

### 2. 可信检索添加（S1~S5、N1）
- 「＋」进入添加页：本地即时过滤，提交后查 USDA FoodData Central（Foundation / SR Legacy / FNDDS；品牌标签类拒收）。
- 候选展示限定词（可可含量/类型/品牌）与「可能匹配」标记；黑巧克力与巧克力饼干明确区分，不自动选首项。
- 点选候选取完整详情后才能添加（每 100 g 四指标 + 折叠的纤维/钠/出处）；显示名与别名可编辑，原始名称与数值不变；身份幂等去重。
- USDA key 一次配置（设置 → 食材资料库，Keychain 存储，与 LLM key 独立，不进备份）；未配置/断网/401/429/超时分别明示，本地能力不受影响。
- 映射硬合同：按官方 nutrient ID 映射；能量口径规则留存（kcal 优先，kJ 换算标推定）；每份不当每 100 g；缺失显示「—」不补零；新增「零食甜食/其他」分类兼容旧备份。

### 3. 可编辑推测配方（R1~R4）
- 我的常吃候选升级「生成参考配方」：先匹配官方候选池，再由已配置文本模型推测原料/用油/成品重，生成「推测配方」初稿进入现有编辑器；失败保留手动建配方。
- 模型边界：只能引用候选池官方 ID（编造即拒）；建议用量最高「估计」；营养值只由资料快照 + 本地计算器得出。
- 油为独立原料行；待匹配原料保留占位（选择/替换/删除），受影响营养按未知传播，不以 0 或完整值冒充。
- 「确认并保存」= 接受为个人参考配方（含推测用量标识）；「重新生成」不覆盖未保存的手工修改，新推测需显式应用；保存走既有版本机制（新版本、旧版本与历史不动）。

### 4. 数据安全
- v10 迁移（v1~v9 不动）+ 配方原料完整营养快照：目录更新/成员移除后旧配方照原值可算（V1）；旧配方启动一次性回填快照，仅用可确认原版本。
- 备份格式 v3：新增官方身份/资料版本/参考表成员（含移除状态、显示名、别名）三文件；幂等恢复；v2 及更早格式兼容导入。
