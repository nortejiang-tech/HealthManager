# HealthManager v0.5.0 发布说明

> 日期：2026-08-16 · build 10 · 同一 Bundle ID（com.norte.HealthManager）覆盖升级
> 性质：架构优化轮 + 数据备份/恢复新功能。未改数据库既有迁移与持久化合同（新增迁移 v6，见下）。

## 新功能：数据备份与重装恢复（ADR-003）

- **自定义备份位置**：设置 → 数据备份 → 选择文件夹（支持 iCloud Drive 等任意可访问位置）；文件夹书签存 Keychain，卸载重装后依然有效。
- **结构化备份包**：退到后台自动导出、手动「立即备份」均可。包内含 `manifest.json`（格式版本、记录数、SHA-256 校验和）+ 11 张解析表的 JSONL 文件 + `settings.json`（配置快照）+ `README.md`。字段字典见 `docs/export-schema.md`，供外部工具/agent 直接读取。
- **重装恢复**：引导页新增「可选：恢复历史数据」步骤；设置页保留手动入口。导入校验版本与校验和、只补缺不覆盖用户数据、投影表覆盖导入（防止重装后空投影行遮挡历史值）、未知文件/字段安全忽略。可重复执行。
- **配置随包走**：对账阈值、仪表盘卡片布局、AI 非敏感配置（端点/模型/预设/配置档）进备份包；API Key 始终留在 Keychain，不进明文备份。
- **明确边界**：备份不含照片与 Apple 健康原始样本（原始样本由 Apple 健康云重新同步）；餐食照片在重装后显示「照片已丢失」占位。

## 体验优化

- **趋势图纵轴自适应**：周/月/年切换与左右滚动时，纵轴跟随可视窗口内数据的最小/最大值缩放，曲线不再被全期间范围压平（柱状图保持 0 基线）。规则抽为 `MetricPresentation` 纯函数并有单测保护。
- **趋势页加载加速**：新增迁移 `v6_dashboard_partial_indexes`（两个部分索引消除原始样本表的全表扫描）；仪表盘刷新信号 350ms 合并；>150ms 加载自动记录日志。
- **证据语义色修正**：饮食热量「不完整」恢复为缺失橙（此前误显估算紫）；用药记录改用 ADR-002 四色语义（此前为系统红绿橙）；全部「状态→颜色」决策集中到 `EvidenceTone` 单一模块。
- 同步中心历史回补天数上限放宽至 365 天。

## 工程收口

- 新增 `SyncJobRecorder`：sync_jobs 信封开/关账唯一入口，删除 4 个 coordinator 中的逐字复制（约 -130 行）。
- `TodayEvidenceLoader` 日期格式化器缓存（消除每餐每记录新建 DateFormatter 的热路径浪费）。
- 设置页新增「逐表行数」诊断面板，便于核对备份/恢复完整性。

## 验证

- 单元测试：290/290 通过（新增 39 个：语义色映射、纵轴自适应、索引迁移、SyncJobRecorder、备份导出→导入→幂等重导→版本/校验/未知文件防御、空投影行回归、settings 回环、Keychain 书签）。
- UI 测试：7/7 通过。
- Debug / Release 构建：0 错误、0 警告。
- 真机（iPhone Air，iOS 26）：全流程实测——文件夹选择、备份到 iCloud Drive、卸载重装、引导页恢复、数据补回、配置机制验证通过；期间修复的三个真机问题（folder picker 无反应、空投影行遮挡 30–90 天数据、配置不随包）已全部闭环。
