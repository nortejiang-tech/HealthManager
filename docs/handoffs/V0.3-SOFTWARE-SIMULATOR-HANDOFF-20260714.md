## 立即停止条件

出现任一情况立即停止该路径、保留日志/截图/设备状态，不做“恢复性”卸载重装或清库：

- 近期备份成功状态或可用恢复路径无法确认，或候选与既有 App 的 Bundle/签名身份不能证明为同一覆盖升级路径；
- 升级启动崩溃、migration 缺失/重复、任何既有数据丢失或字段回退；
- HealthKit 重复样本、误删、删除后残留无法解释，或授权状态与 UI 不一致；
- PhotosPicker/相机操作造成错误覆盖、孤儿文件或取消后持久化；
- VoiceOver 无法到达/操作核心控件、最大字号裁切核心动作；
- sleepAnalysis 合并出现双计、跨日归属错误或把 inBed 当 asleep；
- 后台/前台恢复产生重复同步、长时间 running job 或跨进程状态不一致。

触发后由主架构师建立唯一责任域的修复 STAGE。迁移、HealthKit 幂等、真实数据或跨进程恢复风险不交给低成本 Coder 试错。
